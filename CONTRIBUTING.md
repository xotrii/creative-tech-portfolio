# Contributing

Small, reviewable improvements are welcome.

## Good first contributions

- Add test cases for edge conditions in `src/lib/core.js`.
- Improve keyboard, screen-reader, or reduced-motion behavior.
- Add a deterministic sample without introducing private or copyrighted data.
- Clarify a project limitation or decision in the interface.

## Local checks

~~~bash
npm install
npm run lint
npm test
npm run build
~~~

Please do not commit credentials, personal datasets, copyrighted media, generated engagement, or spam. Describe the user-facing outcome in your pull request.
