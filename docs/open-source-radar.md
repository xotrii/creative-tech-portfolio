# Open-source learning radar

A focused set of projects worth following for the engineering areas represented in this portfolio. A GitHub star should be a genuine bookmark—not an engagement tactic. Read the README, inspect recent activity, and star only what you want to revisit.

## AI and machine learning

- [huggingface/transformers](https://github.com/huggingface/transformers) — model tooling and production patterns
- [scikit-learn/scikit-learn](https://github.com/scikit-learn/scikit-learn) — interpretable classical ML
- [pytorch/pytorch](https://github.com/pytorch/pytorch) — tensor and deep-learning foundations
- [openai/openai-python](https://github.com/openai/openai-python) — typed API client design
- [run-llama/llama_index](https://github.com/run-llama/llama_index) — data frameworks for LLM applications
- [langchain-ai/langchain](https://github.com/langchain-ai/langchain) — composable LLM application patterns
- [microsoft/semantic-kernel](https://github.com/microsoft/semantic-kernel) — agent and orchestration patterns
- [huggingface/diffusers](https://github.com/huggingface/diffusers) — generative media pipelines

## Data products
